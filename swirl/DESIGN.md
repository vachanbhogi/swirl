# Design Specification: Swirl

## Overview

Swirl pairs visual block architecture with a clean, minimal desktop interface built for macOS desktop automation and agentic Jaclang workflows.

## System Architecture

- **Canvas Grid**: Dot-matrix canvas grid for node placement.
- **Node Topology**: Visual blocks mapped directly to underlying Jaclang graph nodes and Walkers.
- **Observability**: Live execution tracing and Jac source code emitter panel.
